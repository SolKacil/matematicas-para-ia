# Libros de referencia

Los libros que sustentan las notas de estudio y los ejercicios de este repositorio.

**Los PDF no se versionan aquí.** Tres de estos libros son de descarga libre y oficial —
abajo está el enlace del autor o la editorial. Los otros tres son obra comercial con derechos
de autor: se consiguen en biblioteca o se compran. Este repositorio no los redistribuye.

| Libro | Autores | Dónde |
|---|---|---|
| *Mathematics for Machine Learning* (2020) | Deisenroth, Faisal, Ong | [mml-book.github.io](https://mml-book.github.io/) — PDF completo, Cambridge University Press |

## Cómo se usan aquí

- **Módulo 1, álgebra lineal:** Larson y Strang para la mecánica y los ejercicios;
  *Mathematics for Machine Learning* (caps. 2–4) para la notación y el enfoque que después
  reaparece en aprendizaje automático.
- **Módulos 2 y 4, cálculo y análisis numérico:** *Mathematics for Machine Learning* (caps. 5 y 7)
  y *Deep Learning* (caps. 4 y 8) para optimización y descenso de gradiente.
- **Módulo 3, grafos y procesos estocásticos:** Bishop para probabilidad y modelos gráficos.
- Ponce Cruz da el contexto de ingeniería en español y las aplicaciones.
